# specs/

Owner: Technical Architect. One spec per Sprint Board story, named `<story-id>.md` (e.g. `SB-7.md`).

Each spec covers: components, interfaces, data, error handling, test approach, and a mapping of every acceptance criterion to how it is met and tested. A story moves to Ready for Dev only when its spec exists, its requirements are Approved and every ADR it depends on is Approved.
