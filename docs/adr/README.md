# adr/

Architecture Decision Records. File name: `ADR-NNN-short-title.md`.

Template sections: Status (Proposed / Approved / Superseded), Context, Options considered (at least two), Decision, Consequences, Links (Sprint Board story, Decisions Log row).

Agents propose ADRs (status Proposed) and log a matching Decisions Log row in Notion. Only Alex sets an ADR to Approved. No spec may build on a Proposed ADR.
